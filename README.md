# AI 魔法翻译官 · 把 AI 名词翻译成人话

> **副标题**：面向中小学的 AI 名词通识学习工具
>
> 不是一本词典，而是一个「**名词翻译机 + 场景模拟器**」——
> 把抽象的英文缩写翻译成孩子听得懂的人话，把陌生的名词放回真实的教学场景里。

## 一、为什么做它

中小学 AI 课最大的难点不是算法，是**名词天书**。

| 课堂上的真实痛点 | 这个 App 怎么解决 |
|---|---|
| 概念太抽象，学生听不懂 | 每条解释都是「一句话人话 + 打比方」，配卡通形象，不出现一句术语套术语 |
| 英文缩写太多，记不住 | 中英文对照 + 按遗忘曲线主动复习，而不是一次性背完 |
| 不知道这个名词能用在哪 | 「场景配对」给出真实场景，让学生反过来选该用哪个名词 |
| 老师不好讲，备课成本高 | 四个单元的完整学习主线，单元解锁制，老师照着走即可 |
| 全班程度不同，进度难统一 | 单元自助解锁 + 图鉴自主检索，快的往前进，慢的回头补 |

核心理念：**不教英文单词，教「这个名词在什么情况下用，能解决什么问题」。**

## 二、它长什么样：五个板块

| 板块 | 解决什么 | 怎么玩 |
|---|---|---|
| **首页 · 名词卡池** | 不想学 | 卡池每天搅一搅，「摇一摇抽一张」，抽到的是一句话讲清楚的名片卡 |
| **学习主线** | 不知从哪学起 | 四个单元、131 个词，逐单元解锁（学到 70% 自动开下一单元），每条可标记「学会了」 |
| **名词翻译机** | 不知道是什么 | 输入英文或中文，给出人话解释 + 真实场景举例 + 分类与等级 |
| **场景配对** | 不知道用在哪 | 每局随机 10 题：给一个真实场景，四个名词里选最合适的，答错会讲为什么 |
| **名词图鉴** | 想找找不到 | 按分类、等级、关键词检索全部词条，可收藏，能看到每个分类的掌握进度 |

另外还有两件事藏在里面：

- **记忆曲线复习**：每天「今日复习」自动挑出该复习的词，学生自评「记得 / 模糊 / 忘了」，系统据此调整下次出现的时间。
- **9 步使用导览**：第一次打开会自动走一遍，把五个标签的用法演示完，不用老师口头交代。

## 三、怎么跑起来

### 最快的方式
打开 → https://ai-term-learning.app.workbuddy.host/ → 直接玩。

### 本地离线用
1. 下载 `app/AI魔法翻译官-App.html`（约 1.4 MB）
2. 双击，用任意现代浏览器（Chrome / Edge / Safari）打开
3. **不需要联网、不需要安装、不需要服务器**——图片和资源全部内嵌在这一个文件里

> 小提示：本地双击打开时显示 **131 条**（用的是文件内部自带词库）；把 `data/terms.json` 放在同目录并通过 http 方式访问时，会自动联网合并线上词库，变成 **132 条**。这是设计好的降级机制，不是缺词。

### 手机上用
同一份 HTML 在手机上打开会自动切换横竖版布局；也支持加入桌面（PWA 式）使用。

## 五、词条是怎么组织的

四个单元，从「AI 是什么」一路走到「让它自己干活」：

| 单元 | 主题 | 词条数 |
|---|---|---|
| 第一单元 | AI 到底是什么 | 35 |
| 第二单元 | 怎么把话说明白 | 35 |
| 第三单元 | 让它自己干活 | 35 |
| 第四单元 | 它是在哪里造出来的 | 26 |
| | **合计** | **131** |

每条词条包含：英文原名、中文译名、**一句话人话解释**、一段展开讲解、难度等级（入门 / 进阶）、所属单元、所属分类标签、以及一张为该概念专门绘制的矢量配图（全部内置，不联网也在）。

## 六、技术说明（一句话版）

**原生 HTML + CSS + JavaScript，零框架、零构建、零外部依赖**，所有图片与图标以 `data:` URI 内嵌，最终产物就是一个能双击打开的 `.html`。

- 学习进度、收藏、主题、音效状态写在 `localStorage`（键名统一为 `aimagic.*`），不上传任何数据，不追踪学生
- 记忆复习采用简化的间隔重复算法：按学生自评等级动态推后下次复习时间
- 深浅色双主题，桌面 / 平板 / 手机三档响应式布局
- 每次修改都配自动化验收脚本合计数百项断言，防止改一处坏一片

详见 `docs/04-技术实现说明.md`。

## 七、这个项目是怎么迭代出来的

从第一行代码到成品，经历了 **27 个版本**，每次改动都留了可点开回溯的快照，全过程记录在演变页里：

https://ai-term-learning.app.workbuddy.host/history/

举几个公开谈也没关系的坑：

- **导览高亮框跟不准**：根因不是定位公式，而是页面全局开了 `scroll-behavior:smooth`，高亮框在页面还在平滑滚动时就去量坐标，量到的是过期位置。修法是导览期间临时关掉平滑滚动 + 补延迟纠正 + 监听滚动跟随。
- **横向漏了一个维度**：给「连标签栏一起框」补了纵向，忘了横向，导致右侧两个标签一直在外面灰着。教训是跨元素框选要四个方向都验证。
- **中文字体与像素风**：中文没有成熟像素字体，最后用「宋体小字号下的点阵渲染」实现，反而更地道。

## 九、写在最后的一点反思

做这个 App 不是为了用 AI 取代老师。

**AI 负责把复杂概念翻译成孩子能懂的话，老师负责引导孩子去动手用这些概念。** 工具降低的是认知门槛，不是教师的价值——这就是我们理解的「人机协同」教学。
