# 《AI 魔法翻译官》项目说明

> 一句话：把 AI 的黑话翻成小学生听得懂的话，并且让它陪着学、陪着练、陪着记住。
>
> 在线体验：<https://ai-term-learning.app.workbuddy.host/>
> 版本演变史（27 个版本，16 个能亲手点开）：<https://ai-term-learning.app.workbuddy.host/history>

---

## 一、我们要解决的问题

学生第一次接触人工智能时，卡住他们的从来不是智力，而是**语言**。

随便打开一篇讲 AI 的文章，满眼是「大语言模型」「上下文窗口」「多模态」「智能体」「推理」「幻觉」。这些词对成年人尚且不友好，对一个十二岁的孩子来说，就是一堵墙。而这堵墙偏偏挡在最前面——**还没进门，先被名词劝退**。

由此产生的三个真实痛点：

| 痛点 | 课堂里的样子 |
|---|---|
| **术语看不懂** | 查了也白查，词典给的解释比原词还难 |
| **懂了也用不上** | 知道「提示词」三个字，轮到自己问 AI 时还是只会打「帮我写一篇作文」 |
| **学过就忘** | 课堂上热闹一场，下周再问，「那个……好像是跟画图有关的？」 |

还有一个绕不开的现实：很多 AI 名词是**专有名词**——「深度求索」「通义千问」这类中文名字，孩子从字面上完全推不出它是什么。这类词最需要的不是解释，是**先见一面**。

## 二、核心理念：翻译，不是教授

这件东西的定位不是课堂替代品，而是**一台翻译机**——把 AI 世界的话，翻译成孩子世界的话。它有一条我始终坚持的原则：

> **用他们已经懂的东西，去解释他们还不懂的东西。**

不是给「上下文」下定义，而是说：*「上下文窗口像一张便利贴，这次用完就扔。」*
不是解释「灾难性遗忘」，而是说：*「像突击复习完物理之后，前面背熟的化学公式全忘了——新知识把旧知识的『位置』占了。」*

这条原则落进产品，就是**三段式释义**——每个词都必须回答三个问题，缺一个都不算讲清楚：

1. **一句话**：这到底是什么？（`one` 字段）
2. **打个比方**：能不能用我生活里的事举个例？（`metaphor` 字段）
3. **什么时候会碰到**：我什么时候真的会遇见它？（`scene` 字段）

第 3 条最容易被忽略，也最要紧。一个学生知道「上下文」的定义毫无意义，直到有一天他跟 AI 聊了半小时，AI 忘了他开头提的要求——**那一刻他需要有一个词，能把这段经历装进去。** 词条里的场景段就是为此存在的。

## 三、面向谁

**主要对象：小学高年级至初中学生**（10–15 岁），作为信息科技 / 人工智能通识课的课堂配套工具。

兼顾两类使用者：

- **学生**：自己抽卡、查词、做题、复习，可以按自己的节奏走
- **教师**：课堂演示、分组活动素材、课后练习材料

设计上刻意做过的取舍：

| 选择 | 理由 |
|---|---|
| 全中文界面，专名附英文原文与缩写 | 英文名不是门槛，但「AI 就是 Artificial Intelligence」这件事值得知道 |
| 语气平等，不讲「小朋友们」 | 这个年纪最反感被当小孩子哄 |
| 深浅色双主题 + 可关音效 | 不同教室设备、不同使用场景都能用 |
| 零安装、零联网依赖 | 农村 / 设备受限的学校，最需要一个能离线跑的版本 |

## 四、功能设计

应用本体是一个单文件网页，顶部 **5 个标签**切换：首页、学习主线、翻译机、场景配对、名词图鉴。

### 1. 首页 —— 今天的入口

- **名词卡池**：一堆卡片沉在池底缓缓搅动，点一下随机抽出一张。抽卡这个动作本身是反功利的——它不要求你带着目标来，**随手一抽也该有收获**
- **今日复习**：按记忆曲线算出今天到期该复习的词，直接给数量与入口
- **学习进度**：已掌握 / 总数、四个单元的完成情况，一眼看到自己走到哪

### 2. 人话翻译机

输入一句听不懂的话或词，返回三层人话解释。**支持模糊搜索与别名匹配**——输入「ai」「人工智能」「artificial intelligence」都能命中同一个词，因为学生不会记得准确的那个名字。

还带「猜你想找」：搜不到完全匹配时给最相近的候选，而不是甩一句「没有结果」把人打发走。

### 3. 场景配对

25 道「这句话在说什么」的情境题：给一段真实发生的小场景，从三个词里挑答案。有计分、连击、答对音效和鼓励动画。

设计要点是**答完必讲原因**（`because` 字段）——不是为了判对错，是为了让学生知道「为什么不是另外两个」。

### 4. 名词图鉴

132 个词条全量可查，可按 **8 个分类**（基础概念、原理算力、感知创作、提示技巧、智能体、安全伦理、产品生态、上下文）与 **2 个层级**（入门 / 进阶）双条件筛选，支持搜索与收藏。

每个词条卡片包含：一句话释义、打比方、真实例子、thinking 提问引导、所属学习单元、一键「学会了」。

### 5. 学习主线（藏在首页里）

四个单元，按认知顺序排，回答四个递进的问题：

| 单元 | 追问 |
|---|---|
| 一、AI 到底是什么 | 先弄清它「是」什么 |
| 二、怎么把话说明白 | 再学会「问」它 |
| 三、让它自己干活 | 然后让它替你动起来 |
| 四、它是在哪里造出来的 | 最后知道它是怎么被做出来的、该信几分 |

这条主线是**导航**，不是必做题——学生可以顺着走完一圈，也可以随抽随停。

### 6. 记得住：一套轻量间隔重复

这是我觉得最值得单独说的一处。每标记一个词「学会了」，系统会按**自己评的四档**（完全忘了 / 有点难 / 记得 / 太简单）算出下次该在哪天再见它。

- 忘了 → 明天必须再见
- 有点难 → 间隔 ×1.35，小步走
- 记得 → 间隔 ×2.0，标准推进
- 太简单 → 间隔 ×3.2，直接跨步
- 上限封顶 180 天，再熟也不彻底失联

这套机制把「学过一个词」从一次性事件，变成一条有回访时间的线。详见`04-技术实现说明.md`。

## 五、教育学依据

| 做法 | 依据 |
|---|---|
| 每段释义都配一个类比 | **具身认知 / 类比迁移**：新知识挂到已有的生活经验上，比凭空建构记得牢 |
| 真实例子必写「我什么时候会碰到」 | **情境学习理论**：脱离情境的知识是惰性的，用不上就等于没学 |
| 先用短句说清，再给类比，最后才给例子 | **最近发展区**：一次只跨一级台阶 |
| 间隔重复 + 自评四档 | **艾宾浩斯遗忘曲线 / 间隔效应**：在快要忘的时刻复习，保持率最高 |
| 抽卡 + 连击 + 音效 | **即时反馈**：低龄学习者对延迟反馈的耐受度很低 |
| 不用哄小孩的语气 | **自我决定理论**：这个年纪对「被当小孩」高度敏感，平等叙述更易内化 |
| 难度分两级、分类分八栏 | **认知负荷理论**：给大量的信息一个可预期的结构 |

## 七、已知边界

诚实交代，省得老师白期待：

1. **它不做生成式 AI**。应用里没有任何大模型调用，不做对话、不写作文。它是一个**学习 AI 名词的工具**，不是一个 AI 助手——这个边界是刻意留的。
2. **中文像素略有妥协**，见 `04-技术实现说明.md` 的限制一节（只在风格样张中涉及）。
3. **数据在浏览器本机**。学习进度存在 `localStorage`，换设备、清缓存不迁移；好处是无需账号、无需服务器，坏处是没有跨终端同步。
4. **词条配图为矢量绘制而非实拍**。这样能保证离线可用、任何时候都清晰，代价是不如实拍真实。
