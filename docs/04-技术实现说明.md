# 技术实现说明

> 配套文件：`app/AI魔法翻译官-App.html`（单文件，约 1.35 MB）

## 一、架构：为什么是「一个文件」

整个应用是**一个 HTML 文件**。HTML、CSS、JavaScript、132 个词条的全部文案、所有矢量插图、所有音效，全部内联在这一个文件里。

选择单文件的理由，按重要性排序：

1. **可离线**：不联网也能用，教室里网络不稳时照样能演示
2. **可分发**：发给老师、拷进U盘、传到群里都是一个文件，不会出现「打开发现少了一半」
3. **零依赖**：不需要 Node、不需要构建、不需要数据库、不需要注册账号
4. **可归档**：每个历史版本就是一个静态快照，能原样保存并重新打开

代价也很实在：文件体积到了 1.35 MB，且无法做代码分割。对一个课上使用的小工具而言，这个交易是划算的。

### 文件内部结构

```
<!DOCTYPE html>
├─ <style>                 全部 CSS（287 个选择器，全部由 CSS 变量驱动）
├─ <body>                  5 个标签页的静态骨架 + 若干空容器（由 JS 填充）
├─ <script>
│   ├─ 数据层       TERMS / BANK / PATH / THINK / GRADES / CATS ...
│   ├─ 工具层       $ / $$ / esc / norm / dayKey / dayAdd / sfx* ...
│   ├─ 存储层       loadLearned / saveLearned / 迁移逻辑
│   ├─ 渲染层       paintGlossary / paintPath / drawOnce / paintProgress ...
│   ├─ 交互绑定     各板块事件监听
│   └─ 启动         paint*() 依次调用
└─ 内嵌 resources   矢量插图（SVG / data URI）
```

## 二、数据层

### 词条结构（131 条内嵌 + 在线合并后 132 条）

```js
{
  id:"context",                    // 唯一标识，存储与跳转都靠它
  cn:"上下文", en:"Context",
  full:"Context Window",           // 完整英文写法
  badge:"CXT",                     // 卡片角标
  cat:"上下文",                     // 8 个分类之一
  level:"入门",                     // 入门 / 进阶
  alias:["上下文","context","窗口"],  // 别名，供模糊搜索命中
  one:"一句话说清这是什么",           // ★ 三段式之一
  metaphor:"打个比方……",            // ★ 三段式之二
  scene:"你什么时候会碰到它……",      // ★ 三段式之三
  short:"卡片背面更完整的一段",
  icon:"node",                     // 矢量插图类型
  keys:["进阶","记得你"],            // 用于 jump 到相关词
  tags:["通识"],
  added:"2026-09-01"               // 录入日期，用于「最新收录」
}
```

**三段式（`one` / `metaphor` / `scene`）是硬约束**，不是可选项。缺任何一段，这个词条就不算写完 —— 这条约束在 132 条里没有例外，
也是这个产品区别于一张「名词解释表」的地方。

## 三、记忆曲线（间隔重复）

这是应用里唯一的「算法」，也是复用了经典 SRS（Spaced Repetition System）思路的地方。

### 四档自评

| 档 | 按钮 | 首次间隔 | 后续乘数 | 含义 |
|---|---|---|---|---|
| 0 | 完全忘了 | 1 天 | `mult:0` | 推倒重来，明天必须再见 |
| 1 | 有点难 | 2 天 | ×1.35 | 小步往前挪 |
| 2 | 记得 | 4 天 | ×2.0 | 标准推进 |
| 3 | 太简单 | 9 天 | ×3.2 | 直接跨步 |

### 计算逻辑

```js
if (g.mult <= 0)      gap = 1;                       // 忘了，归零
else if (!st.gap)     gap = g.gap;                   // 第一次见，用档位基准
else                  gap = Math.round(st.gap * g.mult);
gap = clamp(gap, 1, MAX_GAP);                        // MAX_GAP = 180 天
st.due = dayAdd(gap);
```

设计上的两个刻意之处：

- **有上限 180 天**：再熟也不彻底失联。见过半年不复习就彻底忘干净的
- **忘了是归零而不是减半**：既然自认「完全忘了」，就该诚实重来

### 数据迁移

早期版本的 `learned` 只是个布尔 map（`{id:true}`）。加入 SRS 时没有做破坏性升级，而是**读的时候向下兼容**：遇到非对象值就地转成新的结构，因此老用户的进度一条不丢。

## 四、搜索

唯一值得说的是**为什么要做模糊匹配**：学生来搜的时候，往往记不准那个词。他们会打「ai」「人工智能」「artificial intelligence」，也可能打「上下文窗口」「窗口」。

实现是三层：

1. **完全匹配** `id` / `cn` / `en`
2. **别名匹配** `alias` 数组
3. **子串 / 分词近似**，按相关度排序返回候选（「猜你想找」）

第三层用二元语法（bigram）做相似度，够用且无需引入分词库——一个 132 词的量级用不上真正的分词器。

## 五、存储

全部状态存在浏览器 `localStorage`，一共 9 个键：

| 键 | 存什么 |
|---|---|
| `aimagic.learned.v1` | SRS 复习状态（核心） |
| `aimagic.fav.v1` | 收藏的词条 / 思考题 |
| `aimagic.think.v1` | 思考题的作答痕迹 |
| `aimagic.path.v1` | 学习主线进度 |
| `aimagic.theme.v1` | 深浅色选择 |
| `aimagic.sound.v1` | 音效开关 |
| `aimagic.auto.v1` | 首页卡池是否自动抽 |
| `aimagic.tour.v1` | 首次使用导览是否看过 |
| `aimagic.synced.v1` | 在线词库合并记录 |

**取舍很清楚**：这样不需要账号、不需要服务器、没有隐私顾虑；代价是换设备不同步、清缓存会丢。对课堂场景来说，前者的价值远大于后者。

## 六、在线 / 离线双源词库

这是为了让「老师也能加词」而做的设计：

- **内嵌 `TERMS`**：离线时的全部内容，131 条
- **远程 `data/terms.json`**：联网时自动拉取，与内嵌数据按 `id` 合并去重

```
启动 → 尝试 fetch data/terms.json
     ├─ 成功 → 按 id 合并，未收录的新词追加进卡池与图鉴（记录 synced.added）
     └─ 失败 → 静默降级，只用内嵌数据
```

因此：

- 用 `file://` 直接双击打开 → 看到 131 条（拉不到远程）
- 通过 http(s) 访问 → 看到 132 条

**这不是 bug。** 两条数据源的差集只有一条（`worldmodel` 世界模型），已逐条核对过。

任何一步失败都不会白屏，`catch` 之后安静走本地数据——这是尼尔森可用性十条里「优雅降级」的直接应用。

## 七、矢量插图

132 个词条每个配一张图。全部是**内联矢量绘制**（SVG path / CSS 图形），不用一张位图：

- 优点：任意缩放不糊、体积小（相比 132 张 PNG）、可跟着主题换色、离线可用
- 缺点：绘制质量取决于图形设计，不如实拍真实

这是这个项目里最花时间的一块，也是唯一不能靠写代码解决、必须一点点画的地方。

## 八、导览（做得最细的一处）

首次打开会有一段 **9 步**导览（含首尾欢迎/收场卡），逐步指给你看每个标签在哪。这里有个值得单说的技术坑：

> 高亮框用 `position:fixed` 定位。但页面开了 `html{scroll-behavior:smooth}`，切板块时的「回顶」是**几百毫秒的动画**——而定位只在下一个 rAF 与 190ms 各跑一次。等它读坐标时页面还在滚，**读到的是过期位置，之后再没有纠正的机会**。
>
> 症状是：视口越矮，框偏得越多（900px 高偏 1px，550px 高偏 25px，500px 高偏 37px）。
>
> 修法三层：① 导览全程关掉全局平滑滚动（只在定位函数里局部设 `auto` 不够，上一段动画在跑时会盖掉瞬时跳转）；② 切板块后补两次延迟定位；③ 接上滚动监听。

## 九、已知限制

1. **没有后端**：学习进度不跨设备同步
2. **没有服务端分析**：无法统计学生实际使用情况，只能靠课堂观察
3. **音效是 Web Audio 现场合成**，极少数老旧浏览器不支持，已做 `try/catch` 降级
4. **不支持 IE**，依赖 `CSS 变量`、`grid`、`localStorage`（IE11 及以下全部不满足）
5. **不接入大模型**，见 `03-项目说明.md` 的边界一节

## 十、开发与协作方式

这是一个**人机协作开发**的项目：需求方向、132 个词条的内容编排、学习主线的结构、每天的验收标准由人确定；代码实现、批量数据处理、回归验证由 AI 助手承担。

每一处功能上线前都过了三关：**语法检查 → jsdom 逻辑回归 → 真实浏览器截图核对**。全量验收总计 600+ 条断言，详见 `05-验收报告.md`。
